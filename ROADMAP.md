# Remaining ideas

Current behavior is documented in [README.md](README.md) and its focused references. Completed release checklists live in Git history; superseded briefs live in [docs/archive](docs/archive/README.md).

## Navigation

The selected direction is upward travel from any rotatable house scene, through modeled clouds into Games, with return to the same scene. Direct shortcuts remain available on feature pages. Earlier switch/dock/launcher studies remain available at `npm run preview:navigation` as optional design references, not pending decisions.

## Engineering

Prioritized, evidence-based follow-ups are in [the audit](docs/audit.md): consolidate CSS, split large feature controllers by responsibility, and measure current house/atlas performance. Avoid large rewrites without a demonstrated benefit.

## Optional product work

These are ideas, not enabled features or instructions to implement:

- Recurring events and external event guests.
- Itemized receipts and guest payers.
- Utility-credit rewards only after rules for funding, budget, eligibility, ties and corrections are agreed. Keep them independent of existing accounting until explicitly designed.
- Atlas forest/glacier land-cover detail; current terrain colors are illustrative.
